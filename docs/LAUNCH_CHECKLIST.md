# Launch checklist

- [ ] Review legal entity, privacy terms, data processing agreements and child-data obligations.
- [ ] Configure Supabase Auth URLs, email confirmation, backups and database monitoring.
- [ ] Apply and review migrations; test tenant isolation and role boundaries with separate schools.
- [ ] Complete staff/student/parent flows, authorization, records retention, export and deletion workflows.
- [ ] Configure verified email sender and templates; test delivery and failure handling.
- [ ] Configure Gemini and payment provider secrets only after their guarded workflows are implemented.
- [ ] Implement and verify payment webhooks, idempotency, cancellation and renewal behavior.
- [ ] Run unit, integration and end-to-end tests for critical school workflows.
- [ ] Set Vercel preview/production variables and callback URLs; verify HTTPS and error monitoring.
- [ ] Validate backup restoration and incident response before onboarding real schools.
